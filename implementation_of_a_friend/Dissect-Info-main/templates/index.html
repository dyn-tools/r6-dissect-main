Cheat Engine workflow for finding player position/rotation:
1. Launch R6 Siege, start a custom game on the same map
2. Open CE → attach to RainbowSix_Vulkan.exe (or RainbowSix.exe)
3. Value type: Float  |  Scan type: Exact Value
4. Find your Y (height) first — stand still on flat ground, scan ~1.5. Jump, rescan for new value. Repeat until narrowed down
5. Right-click result → Browse this memory region — look for XYZ as 3 consecutive floats
6. Note the 4–8 bytes immediately BEFORE the XYZ triplet — this is likely a marker/type byte we can use as a Listen() pattern
7. Enter that X, Y, or Z value in the float finder below to locate it in the replay binary
8. Compare surrounding bytes in CE memory vs. replay binary to identify the packet structure
